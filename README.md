# NoCtrl — Захист комбінацій клавіш

Веб-розширення (Manifest V3) для Chrome, Edge, Brave, Opera та інших браузерів на базі Chromium, яке перехоплює обрані вами комбінації клавіш, події буфера обміну (`copy`, `cut`, `paste`) та контекстне меню (`contextmenu`) **до того, як їх побачать скрипти веб-сторінки**.

## Як це працює

- Скрипт розширення (`content.js`) підключається на етапі `document_start` у всіх фреймах (`all_frames: true`).
- Слухачі реєструються на об'єкті `window` у фазі перехоплення (`capture: true`), тому спрацьовують раніше за будь-які обробники сторінки.
- Для збігів викликаються `event.stopImmediatePropagation()` та `event.stopPropagation()`, але **не викликається** `event.preventDefault()`. Завдяки цьому стандартна дія браузера (копіювання, пошук, відкриття DevTools, контекстне меню) виконується як зазвичай, а JavaScript сайту не отримує інформацію про подію і не може її заблокувати.
- Зіставлення клавіш виконується за `event.code`, тому комбінації на кшталт `Ctrl + C` працюють однаково на англійській та українській розкладках.

## Встановлення (режим розробника)

1. Відкрийте сторінку керування розширеннями у вашому браузері:
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
   - Brave: `brave://extensions`
2. Увімкніть перемикач **Режим розробника** (Developer mode).
3. Натисніть **Завантажити розпаковане розширення** (Load unpacked).
4. Оберіть папку `c:\Projects\NoCtrl`.

## Можливості

- **Глобальний та по-сайтовий перемикач** — можна миттєво поставити захист на паузу для конкретного домену або загалом.
- **Інтерактивний запис комбінацій** — додавайте будь-які власні комбінації чи окремі клавіші (напр. `Ctrl + S`, `Alt + K`, `F12`) у popup-вікні, вимикайте чи видаляйте їх.
- **Стандартний набір** — `Ctrl+C`, `Ctrl+V`, `Ctrl+X`, `Ctrl+A`, `Ctrl+F`, `Ctrl+Shift+I`, `F12`.
- **Захист буфера обміну та ПКМ** — окремі перемикачі для подій `copy`, `cut`, `paste` і `contextmenu`.
- **Лічильник та журнал на вкладці** — бейдж на іконці розширення та живий список заблокованих подій у popup.

## Тестування

У проєкті є файл `test-page.html`, який імітує сторінку зі скриптами перехоплення клавіш, буфера та правої кнопки миші.

> Щоб протестувати `test-page.html` без локального сервера (через `file://`), відкрийте деталі розширення на сторінці `chrome://extensions` та увімкніть **«Дозволити доступ до URL-адрес файлів»** (Allow access to file URLs).
