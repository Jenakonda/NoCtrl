Ворожий тестовий стенд для NoCtrl

Сторінка імітує сайт із захистом від розширень: сканує DOM/прототипи, запускає синтетичні пастки dispatchEvent та розставляє 8 каналів шпигунства за клавішами, буфером обміну, виділенням і фокусом.

Якщо ви відкрили сторінку як file:///..., увімкніть «Дозволити доступ до URL-адрес файлів» у налаштуваннях розширення (chrome://extensions → Деталі).

Модуль 1. Сканер виявлення розширень (Anti-Extension Detector)

Перевіряє, чи залишається NoCtrl невидимим для скриптів сторінки.

Модуль 2. Полігон для тестування (спробуйте заблоковані комбінації)

Натискайте Ctrl+C, Ctrl+V, Ctrl+X, Ctrl+A, Ctrl+F, Ctrl+M, Ctrl+Enter, F12, виділяйте текст або тисніть ПКМ. Коли NoCtrl працює, лічильники нижче мають залишатися на 0, а нативні дії браузера — працювати.

Редагований блок для перевірки вставки (Ctrl+V), вирізання (Ctrl+X) та Ctrl+Enter без витоку через InputEvent.
Захищений текст (пастка selectstart): Спробуйте виділити цей абзац мишею. Без NoCtrl скрипт сторінки викликає e.preventDefault() на selectstart та блокує виділення. Із NoCtrl текст виділяється вільно.
